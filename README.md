# Nischith N. // Portfolio

A high-performance, dark-mode focused, glassmorphism UI portfolio showcasing hardware design engineering, verification projects, and creative UI/UX work.

## 🚀 Features
- **Interactive Linux Terminal**: A fully functioning fake terminal in the "Story" section with custom commands (`help`, `whoami`, `party`, `invert`, `chill`, `destroy`).
- **Hardware Project Showcase**: Glassmorphic UI cards detailing advanced VLSI projects (SHA-256 Accelerator, DMA Controller, NeuraRTL) with hover glitch effects.
- **Design Portfolio Gallery**: An interactive on-hover burst gallery that elegantly scatters project images with fluid animations.
- **Responsive & Accessible**: Optimized for both mobile and desktop with a consistent pixel-perfect dark mode aesthetic.
- **Premium UI/UX Aesthetics**: Ambient background gradients, CRT scanline overlays, custom SVG favicons, and a trailing magenta cursor.

## 💻 Tech Stack
- HTML5, Vanilla JavaScript, CSS3
- TailwindCSS (via CDN) for utility layout structure
- Google Fonts (`Space Grotesk`, `Manrope`, `JetBrains Mono`)

## 🛠️ Setup & Deployment
This project is entirely client-side and requires no build steps. 

To run locally:
1. Clone the repository.
2. Open `index.html` in any modern web browser.
*(Optionally use Live Server in VS Code for live reloading during development).*
